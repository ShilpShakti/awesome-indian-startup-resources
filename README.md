## 🏛️ Government Schemes & Registration

| Resource | क्या है |
|---|---|
| [Startup India Portal](https://www.startupindia.gov.in/) | DPIIT recognition के लिए official hub — ज़्यादातर schemes के लिए यह पहला step है |
| [Startup India Seed Fund Scheme (SISFS)](https://seedfund.startupindia.gov.in/) | Early-stage startups के लिए ₹20 लाख तक grant + ₹50 लाख तक convertible debt |
| [Credit Guarantee Scheme for Startups (CGSS)](https://www.startupindia.gov.in/content/sih/en/loans-for-startups/credit-guarantee-scheme-for-startups.html) | DPIIT startups के लिए collateral-free loans (उच्च limit तक) |
| [PM MUDRA Yojana](https://www.mudra.org.in/) | Micro/small businesses के लिए collateral-free unsecured loans |
| [Stand-Up India](https://www.standupmitra.in/) | SC/ST और महिला entrepreneurs के लिए bank loans |
| [Atal Innovation Mission (AIM)](https://aim.gov.in/) | NITI Aayog की innovation व entrepreneurship पहल |
| [Women Entrepreneurship Platform (WEP)](https://wep.gov.in/) | NITI Aayog — महिला-नेतृत्व वाले startups के लिए mentoring व funding access |
| [myScheme](https://www.myscheme.gov.in/) | केंद्र + राज्य सरकार की सभी schemes खोजने का unified portal |
